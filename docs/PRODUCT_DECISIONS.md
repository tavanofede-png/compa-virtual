# Decisiones

| Decisión                                | Motivo y consecuencia                                                                                                                                                     |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Nombre temporal Compa Virtual           | Puede cambiar antes de registrar identificadores definitivos                                                                                                              |
| Adolescentes en 3D estilizado detallado | Dirección elegida por el usuario: acabado de videojuego cuidado, materiales diferenciados y habitación con profundidad. Reemplaza las criaturas y el pixel art iniciales. |
| Web + Android + iOS                     | Cliente web estático y componentes nativos; lógica y arte compartidos                                                                                                     |
| Supabase                                | Auth, datos, archivos privados, RLS, colas y funciones en un núcleo                                                                                                       |
| OpenAI en lugar de Gemini               | Decisión contractual confirmada en el plan; no se integra la clave anterior                                                                                               |
| Sin cobros ni cupos diarios de IA       | Una consulta concurrente por cuenta evita carreras y abuso de infraestructura                                                                                             |
| Agregado versionado con proyecciones    | Atomicidad sencilla para piloto pequeño; refactorizar antes de una escala elevada                                                                                         |
| Confirmación de extracciones            | Las fechas ambiguas no se convierten en compromisos automáticos                                                                                                           |
| Planes aceptados                        | Replanificar requiere una nueva aceptación; historial conservado                                                                                                          |
| Libro de monedas                        | El cliente no modifica saldos; no se retiran objetos comprados ni XP histórica                                                                                            |
| Penalizaciones acotadas                 | Solo incumplimiento reconocido, excepciones y saldo no negativo                                                                                                           |
| Retención de chat 30 días               | Memoria académica explícita separada y editable                                                                                                                           |
| Demo local identificada                 | Permite revisar la experiencia sin simular IA, registro o servicios conectados                                                                                            |
| Native push separado de OCR             | Un documento pesado no ocupa el ejecutor de recordatorios                                                                                                                 |
| Interfaces de extensión sin UI inactiva | Classroom, voz, grupos y cobros quedan para etapas posteriores                                                                                                            |
| Revisión pedagógica/jurídica humana     | La implementación técnica no certifica por sí misma aptitud para menores                                                                                                  |
