# Roadmap y preparación de beta

## Implementación de desarrollo

Web, cliente nativo, lógica compartida, migración reproducible, control de versión, RLS, materiales, proveedor de IA, recordatorios, privacidad y demostración. La compilación local y los tests cubren la base técnica indicada en VALIDATION.md.

## Conexión real

Seleccionar la organización de Supabase y crear un proyecto dedicado. Aplicar migración/seed; desplegar API, worker y programador; configurar OpenAI; verificar acceso al modelo y comportamiento con datos ficticios. Vincular EAS e identificadores de las tiendas.

## Validación funcional

Recorrido completo con dos adultos de prueba en las tres plataformas. Revocar tokens, usar modo avión, reintentar desde dos dispositivos, reiniciar el worker durante OCR, subir archivos dañados/cifrados, verificar búsquedas cruzadas y eliminar cuenta con documentos en cola.

## Evaluación con el equipo

Aprobar prompts y 17 métodos. Revisar el balance de monedas, límites diarios y autonomía. Corregir respuestas ambiguas, tono y exactitud antes de incorporar estudiantes.

## Habilitación para alumnos

El abogado revisa identificación del titular, consentimiento, privacidad y transferencias. Verificar controles de datos con el proveedor, incluyendo ZDR cuando corresponda. Después de confirmar estas condiciones, habilitar las cuentas elegibles y distribuir la beta por TestFlight y Google Play.

## Posterior

Classroom, voz, widgets, juegos educativos, rankings/grupos, cobros y espacios para padres/profesores. Mantener la métrica de acciones académicas completadas, sin optimizar permanencia.
